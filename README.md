 - ## Новый функционал

### Модуль для работы с CSV и Excel файлами

Этот модуль включает функции для загрузки данных из файлов в формате CSV и XLSX. Каждая функция возвращает данные в виде списка словарей, что упрощает дальнейшую работу с ними.

#### Функции

- **`load_csv(file_path: str, delimiter: str = ";") -> List[Dict]`**
  - **Описание:** Загружает данные из CSV файла и возвращает список словарей.
  - **Параметры:**
    - `file_path` (str): Путь к файлу CSV, который нужно загрузить.
    - `delimiter` (str, по умолчанию ";"): Символ, используемый для разделения значений в файле.
  - **Возвращаемое значение:** Список словарей, где каждый словарь представляет собой строку данных из CSV файла с именами колонок в качестве ключей.
  - **Исключения:**
    - **FileNotFoundError:** Если указанный файл не найден.
    - **Exception:** В случае других ошибок при загрузке.

- **`load_xlsx(file_path: str) -> List[Dict]`**
  - **Описание:** Загружает данные из XLSX файла и возвращает список словарей.
  - **Параметры:**
    - `file_path` (str): Путь к файлу XLSX, который нужно загрузить.
  - **Возвращаемое значение:** Список словарей, где каждый словарь представляет собой строку данных из XLSX файла с именами колонок в качестве ключей.
  - **Исключения:**
    - **FileNotFoundError:** Если указанный файл не найден.
    - **Exception:** В случае других ошибок при загрузке.
